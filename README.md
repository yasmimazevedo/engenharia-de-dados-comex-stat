# Engenharia de Dados — Comex Stat

Projeto de Engenharia de Dados desenvolvido a partir dos dados públicos do Comex Stat.

## Escopo

Análise comparativa do comércio exterior de Minas Gerais durante o primeiro semestre de:

- 2024;
- 2025;
- 2026.

Serão analisadas exportações e importações entre janeiro e junho de cada ano.

## Análises planejadas

- evolução mensal e anual;
- principais países parceiros;
- produtos mais exportados e importados;
- valor FOB por produto;
- peso líquido movimentado;
- principais vias de transporte;
- relação entre produtos e países;
- comparação entre exportações e importações;
- evolução do preço médio por quilograma;
- produtos com crescimento ou queda.

## Tecnologias planejadas

- Python;
- Pandas;
- PostgreSQL;
- SQL;
- Git e GitHub;
- Power BI;
- Docker e Airflow em etapas futuras.
